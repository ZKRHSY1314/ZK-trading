## 训练前必须修正

### 1. `risk_level` 存在非 schema 枚举值

当前 schema 只允许 `low`、`medium`、`high`，但实际数据里有 6 条不合规值：

| pattern_id | pattern_name | 当前 risk_level | 建议 |
|---|---|---|---|
| `LEGACY_VP_SINGLE_006` | 缩量小阴小阳线 | `low_to_medium` | 改为 `medium`，另加 `risk_range_note` |
| `LEGACY_VP_SINGLE_008` | 缩量中阴中阳线控盘信号 | `medium_to_high` | 改为 `high` 或 `medium`，另加说明 |
| `LEGACY_VP_UP_004` | 放量大涨 | `medium_to_high` | 改为 `high` 或 `medium`，另加说明 |
| `LEGACY_VP_DOWN_002` | 放量小跌 | `medium_high` | 改为 `high` |
| `LEGACY_VP_INTRADAY_003` | 45度角放量拉升 | `medium_high` | 改为 `high` |
| `LEGACY_VP_INTRADAY_004` | 分时上升持续放量 | `medium_high` | 改为 `high` |

### 2. 证据字段缺失较多

- `evidence_summary` 为 `null`：142 条。
- `rule_logic` 为空字符串：223 条。
- `training_notes` 为空字符串：195 条。
- `trigger_conditions` 为空列表：152 条。
- `preconditions` 为空列表：184 条。
- `invalidation_conditions` 为空列表：169 条。

这会影响模型学习“为什么触发”和“什么时候失效”。训练前至少要补齐 `evidence_summary`、`trigger_conditions`、`negative_filters`、`invalidation_conditions`，否则模型容易只记住形态名称，而不是学习可验证条件。

### 3. 旧数据有 24 条 `observable_features` 字符串化列表

例如 `observable_features` 中出现 `"['大阳线']"` 这类字符串，应改成真正的列表项：`"大阳线"`。否则后续特征抽取、相似度聚类、规则匹配会出现噪声。

### 4. 标签分布偏弱，少数类太少

动作标签分布：

- `REDUCE_OR_EXIT`：64
- `SIM_BUY_CANDIDATE`：63
- `WAIT_CONFIRMATION`：59
- `HOLD_OR_TRAIL`：19
- `AVOID_OR_WAIT`：11
- `RISK_ALERT`：6
- `NO_TRADE`：3

如果直接训练分类模型，`RISK_ALERT` 和 `NO_TRADE` 很可能学不好。训练前应扩充风险、观望、不交易样本，或在训练时做分层采样、类别权重和风险优先评估。

### 5. 目前是规则弱标签，不是历史行情监督样本

数据集中没有真实 `signal_date`、`stock_code`、`entry_price`、`exit_price_*`、最大有利/不利波动、回撤、基准收益等字段。因此它不能证明某个形态有收益，只能证明“教学资料中如何描述这个形态”。

训练阶段应另建实例级数据集：

```text
- pattern_id
- signal_date
- stock_code
- as_of_timestamp
- feature_snapshot
- action_label
- forward_return_1d/3d/5d/10d
- max_favorable_excursion
- max_adverse_excursion
- drawdown
- turnover_rate
- volume_ratio
- limit_status
- benchmark_return
- split_tag
```

## 建议改进顺序

1. 先修 schema 和字段枚举，让校验能真正挡住异常值。
2. 统一 `risk_level`，把区间风险放入单独说明字段。
3. 修复 24 条字符串化列表特征。
4. 补齐 `evidence_summary`、`trigger_conditions`、`invalidation_conditions`。
5. 增加 `quality_score` 或 `evidence_level`，区分“原文规则”“人工整理”“回测验证”“样本外验证”。
6. 建立历史行情实例集，并按时间切分 train / validation / test / out-of-sample。
7. 对风险类和不交易类补样，避免模型过度偏向买入/卖出候选。
8. 在训练前冻结数据版本，保存 manifest、schema、切分规则和审计说明。
