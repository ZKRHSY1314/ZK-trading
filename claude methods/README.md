## 本轮最重要的三个发现

1. **39 次回测全部 0 笔成交**，根因已定位并复现：回测快照缺 `pb`/`market_cap_billion`，
   灯盏规则永远返回 False，tier 上限 44.4 分打不到 80。→ `01` 第二节
2. **系统唯一测出来的信号是反向的**：Rank IC −0.169，Top5 次日超额 **−2.25%**，
   而 11–20 名 +0.41%，单调。但只有 6 个决策日、只标注了 h=1，**结论未定** —— 需先补 h=5/20。→ `01` 第一节
3. **五条互不相通的选股链路**：被度量的、界面展示的、回测的，是三套不同的代码。反馈回不到策略。→ `01` 第三节
