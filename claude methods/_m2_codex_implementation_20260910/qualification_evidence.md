# 同花顺 M2 源资格证据

Codex 实施并提交独立复核。这里核实的是固定本地接口与保留响应的语义，不是投资决策，也没有修改历史 Sina 失败记录或启用实盘。机器工件为 `qualification_evidence.json`；原8次采集的请求、响应、进程证明与生产程序哈希保持原样。

## 复权依据

不能由 `adjustment=0`、同源两份数据相等、或枚举名字单独推出厂商已按不复权返回。本规则同时要求：

1. 静态链钉住已加载适配器 SHA256 `19fbd895…3469b`：契约 `Unadjusted=0` 经 `ResolveRightStatus` 传到宿主 `RightStatus.Exclude=0`，再进入价格查询协议；保留完整 IL 与枚举证据。
2. 同一证券和完整区间真实请求 0/1/2。两个调整价格控制都必须与0发生变化，三者成交量/成交额逐日必须不变，日期键相同。
3. 用独立官方实施公告的真实除息日和税前每股人民币现金，检查全部 OHLC 的准确关系：`P0(t)−P1(t)=t日之后本区间全部已实施现金之和`。不拟合容差、不移动日期，不用价格结果反推公告现金。
4. 所有进入候选库的股票都再次通过原始数值、证券身份和原冻结M1 P4逐日 `low*0.98 ≤ amount/volume ≤ high*1.02` 检查。另保留更严格的 `low ≤ amount/volume ≤ high` 全量诊断，但不把额外诊断偷偷升格为原合同没有的新门槛。原P4将非正量额隔离，出现隔离行不能变成PASS。指数免股票流动性判断，`instrument_class=benchmark`且`unit_status=not_applicable`，不宣称指数交易单位已证明。
5. 绝对量额单位由独立SSE锚点和本地真实字段/显示链组合核实；包络本身不能区分量额同时放大相同倍率。单位判断严格绑定下文已审原始证据哈希，不能换一组数值恰好“最接近1倍”的输入就放行。

## 单位政策与数值准确性分开

本次把字段13/19的原样取值链、沪深京股票每手100股的真实展示换算链，与两日同证券、同交易范围的上交所独立原始成交记录结合。上交所接口原值经其展示脚本除10000才显示“万股/万元”，因此原量为股、原金额为人民币元。本地链直接支持股数单位；金额的币种和绝对倍率由这组外部锚点补足。

|日期|字段|SSE原值|THS原值|THS−SSE|
|---|---|---:|---:|---:|
|2022-11-29|volume|131565868|131565868|0|
|2022-11-29|amount|1030152542.00|1030152540|−2.00|
|2026-05-29|volume|455150398|455150400|2|
|2026-05-29|amount|3878787080.00|3878787100|20.00|

不把这些小差额抹平，也不要求对一般来源数据新增精确相等门槛。保留的HxLong/Double静态格式及四项固定分辨率对照是支持材料，不能证明实际transport、服务端编码器或Single dtype。binary32相等完全不参与资格决定；例如131565868本身就不是精确binary32值。

纯数值函数对预先列出的单位倍率（1、100、1e4、1e8及倒数）作对称倍率距离排序，用于反证常见量纲错误；没有拟合新的百分比或绝对误差阈值。该排序本身也不能批准任意严重偏差：builder先硬核对实际锚点工件SHA `fc812f6664a7eb3b2646e20454102cf13f27fc0769d21bfe6107191c1d777fda`、静态语义报告SHA `7e2d12f3ff2ecf0d4c119608b811563f2832db9e69b6d3a82ee0ab5c48a973bd`、静态核对JSON SHA `3256db3834097decbd5d8fb6fd90ec3cecca7f8ff1711f8a8b5483d01a56c88d`，并从原始SSE和THS body重算日期、身份、字段值和差额。换锚点后，即使1倍仍排第一也立即拒绝，必须另行独立复核。合成测试覆盖替换锚点、量额同时乘或除1e4、无静态语义/无官方原件、伪造binary32标记及P4失败/隔离。

该组合验证基础单位，而不是证明所有数值无限精确。scope与bundle明确保存 `all_value_accuracy_verified=false`。每只目标股仍须自身原始响应的原M1 P4 PASS；指数继续为not_applicable，不被单位函数当成股票。当前两只控制股的组合单位规则PASS可供root独立复核，`review_state=ready_for_independent_review`不冒充已经独审。

## 复现与范围

`qualification.py`为纯数值诊断，无网络、数据库或运行时provider导入；29个测试覆盖现金事件、OHLC、原P4、绝对单位证据及builder证据绑定。`official/build_qualification_evidence.py`只读保留的文件，输出请求规范JSON哈希、原始body哈希、真实completion哈希、原始producer_pins哈希、每scope实际preflight哈希、适配器哈希和规则哈希所绑定的scope。

builder依原plan.kind选择真实入口：原8次为capture.py，后48次为collect_remaining.py，后者依赖的capture.py仍须原始producer manifest哈希全部一致。scope先加入自己的body、receipt、preflight、producer和实际入口工件，再生成证据引用；不能漏引用而借用上一证券的工件。独立请求JSON存在时同时保留其原始文件哈希，与规范payload哈希明确区分。冻结manifest恰好52项且包括两只基准，未把名称为stocks的旧变量误解为应缩到50项。
