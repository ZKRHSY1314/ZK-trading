## 后续读取程序必须保留的语义

1. 价格、基准、停牌、公司行动和上下文均须按各自的决策截点与证据时间规则消费。索引包含完整研究区间，不代表整份索引可以作为任意历史日期的已知事实。未来事件不能改变早期标签或早期案例身份。
2. 采集时间是 2026 年本地获取证据的时间，不是历史行情在当时已进入此系统的证明。文档 URL 中的日期、文件修改时间、证据整理时间不能替代原始可得时间。因此整体 strict PIT 保持 false。
3. 停牌证据包含事后复牌公告。可用它核对回顾性缺口原因，不能伪装成当时已经知道复牌日。
4. 已知分红事件与覆盖未知可以同时存在。没有列出事件不能转换成“未发生公司行动”，也不能推导完整复权因子；已知跨事件的未复权收益、止损和目标价须按验收后的规则保守处理。
5. 名称和 pilot 分层只保留为来源说明；不得借当前名称推断历史 ST 状态，不得重复使用旧 pilot 覆盖率作为本轮数据质量结论。
6. 北京市场个别价格域的原有条件性解释完整保留，不提升为厂商专有口径证明或全量价格准确认证。
7. 本索引不采用训练/验证切分、不挑选案例、不改变规则阈值。后续执行必须使用 Codex 验收并冻结的策略版本，先按已授权阶段处理开发区间，保留验证与最终留出区间的用途限制。

M2 冻结数据库、旧标签、知识文件和生产状态保持原样；没有新采集、账户访问、实盘交易或 M4 操作。
